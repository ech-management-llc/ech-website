# How to change the rental website — by email

You do not need to log into anything. You do not need a password.
**You just send an email.** That's it.

---

## The one-minute version

Send an email to **jerry.eads@echmanagement.services**

Put this in the **subject line**:

```
LISTING: 124 Pierce leased #PROCEED
```

Leave the message blank. Hit send. Done.

Within an hour the website updates itself, and you get an email back telling you what changed.

---

## What each part means

```
LISTING:  124 Pierce   leased   #PROCEED
   |          |           |         |
   |          |           |         └─ the password word. Without it, nothing happens.
   |          |           └─ what changed
   |          └─ which house
   └─ tells the system this email is about the website
```

**Think of it like leaving a note for someone.** You say what house, what changed, and you sign it
so they know the note really came from you.

## Real examples you can copy

A house got rented:
```
LISTING: 124 Pierce leased #PROCEED
```

A house is empty again and ready to rent:
```
LISTING: 124 Pierce available, 1400 #PROCEED
```

You changed the rent:
```
LISTING: 102 Remington 1950 #PROCEED
```

One apartment in a building got rented:
```
LISTING: 13074 unit 1 leased #PROCEED
```

Three apartments are open at LC Way:
```
LISTING: LC Way 3 units open #PROCEED
```

You want to say something extra on the page:
```
LISTING: 500 Reynolds note Available September 1 #PROCEED
```

**You do not have to match these word for word.** Write it how you'd say it out loud. Just make
sure you name the house and end with `#PROCEED`.

---

## About that word `#PROCEED`

This is the safety lock. **Nothing happens without it.**

Here's why it exists. Anyone in the world can send an email that *looks* like it came from you —
it's easier than you'd think. So instead of trusting the name on the email, the system looks for
this word. Only you and Jerry know it.

If you forget it, you get a friendly reminder email and nothing changes on the website. No harm
done. Just send it again with the word.

**Don't put `#PROCEED` in emails to anyone else.** Keep it between you and Jerry.

## Adding pictures

Pictures take one extra step, because they can't ride along in the email.

1. **Take the pictures on your phone.** Normal photos, any size, don't worry about it.
2. **Send them to the picture folder.** Tap Share → Google Drive → pick the folder called
   **ECH_LISTING_PHOTOS**
3. **Then send the email:**
   ```
   LISTING: 124 Pierce photos #PROCEED
   ```

The first picture becomes the big one on the listing. If you want a certain one to be the big one,
just say so:

```
LISTING: 124 Pierce photos, use the kitchen one first #PROCEED
```

### Two things about pictures

**The folder will look empty.** That's normal. It's like a mailbox — you drop things in, and the
system takes them out. Empty means it already picked them up.

**Your phone secretly tags photos with the exact address they were taken at.** The system strips
that out before anything goes on the website. Nobody browsing rentals can see where the picture
was taken.

## If you made a mistake

**Reply to that email with the word `revert`.**

It puts things back exactly how they were. Every change is saved separately, so undoing one thing
doesn't disturb anything else.

You can also just send a new email fixing it. Marked a house rented by accident?

```
LISTING: 124 Pierce available, 1400 #PROCEED
```

---

## Things it will never do

It's built to be careful, not clever.

- **It won't guess.** If it can't tell which house you mean, it emails you and asks. It does not
  pick one and hope.
- **It won't make up a price.** If it doesn't know the rent, the listing shows no price rather than
  a wrong one.
- **It won't touch anything else on the website.** Only the rental listings. It can't change the
  phone number, the About page, or anything else.
- **It won't put renter information online.** No names, no lease dates, nothing private. Ever.

## If nothing happens

Give it an hour first — it checks a few times a day, not the instant you hit send.

Still nothing? In order:

1. **Check the subject line has `#PROCEED`** at the end. This is the usual reason.
2. **Check you sent it to** `jerry.eads@echmanagement.services`
3. **Check your sent folder** — make sure it actually went
4. **Tell Jerry.** He can make the change directly in about ten seconds, and figure out what went
   wrong afterward.

Nothing you can type in an email can break the website. The worst case is that nothing happens.
